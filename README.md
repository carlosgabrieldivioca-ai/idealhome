# idealHome V3

Versão de teste do site em Python + Django.

## Para abrir

1. Extraia esta pasta.
2. Dê duplo clique em `ABRIR_IDEALHOME.bat` no Explorador do Windows.
3. Não abra o `.bat` dentro do VS Code.
4. O script instala o ambiente, atualiza a base, importa os 3.081 anúncios organizados e abre o navegador.

A V1 permanece como cópia de segurança.
